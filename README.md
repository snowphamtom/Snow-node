# Nine Circles — process documentation

Original nine-movement artwork series after Dante's *Inferno* (Limbo, Lust,
Gluttony, Greed, Wrath, Heresy, Violence, Fraud, Treachery), entered in the
ASUS UGen AI League, Stage I, Creator AI theme, by Taylor Heller / Monsters Ink LLC.

This repository holds the **process documentation** for the entry: how the series
was authored, under what locked conventions, and with what verifiable file trail.
The nine final artworks themselves are filed with the competition entry, not
published here.

## Contents

- `PROVENANCE.md` — what the file record shows: render timestamps, SHA-256 manifest,
  development lineage, and the four verifiable behaviors of the directed process.
- `manifest.sha256` — hashes of the nine frozen final pieces.
- `CONVENTIONS.md` — the nine compositional conventions locked in writing during
  the authoring sessions.
- `REJECTED.md` — rejected branches, retained on file.
- `scripts/build_asus_video.py` — the Ken Burns render script that assembled the
  2:48 demo video (1080p24) from the nine pieces.
- `scripts/make_nine_sounds.py` — the synthesis script for the video's score:
  nine distinct movements, one per circle.

## Method in one paragraph

Reference-driven synthesis: the author supplied reference imagery per circle,
rejected directions outright (rejected branches retained, not deleted), locked
written compositional conventions, and rendered the nine finals as a locked batch
once the visual language was set. Every step timestamped; every final hashed.
